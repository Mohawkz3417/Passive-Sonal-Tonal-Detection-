This folder holds materialized datasets and runtime logs.

- `demo_samples/` -- 20 example (spectrogram, mask) pairs generated by
  `05_Dataset_Generator/dataset_builder.py::materialize_dataset()` at
  SNR uniformly sampled in [-10, +20] dB, for quick inspection without
  running the generator yourself. Each `.npz` has keys `img` (1,F,T
  normalized PCEN spectrogram), `mask` (1,F,T binary ground truth), and
  `snr_db`.

- `detections_log.csv` -- superseded by `logs/detections_log.csv` (+ a
  human-readable `logs/detections_log.txt`) at the project root, created
  automatically the first time `03_Live_Detector/live_detector.py` or
  `deploy.py` runs; every confirmed detection (timestamp, frequency,
  confidence, SNR, bandwidth, harmonics, inference time, CPU usage) is
  appended there. See `13_Scripts/log_utils.py`.

- `generated/` -- output of `04_Signal_Generator/generator_cli.py`: WAV
  + spectrogram/PCEN/mask PNGs + metadata JSON per generated clip.

- `snapshots/` -- PNG snapshots saved from the Live GUI's "Save" button.

Training itself does **not** read from this folder by default -- it
generates data on the fly for speed and variety (see
`05_Dataset_Generator/dataset_builder.py::TonalSegDataset`). Materialize
a fixed set here only when you want a repeatable benchmark set or plan
to mix in real-recording-derived samples later.
